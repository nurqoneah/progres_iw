Integrasi Mesin Oplos Cat (Modul Tinting)

Modul digi_tinting_base saat ini berstatus uninstalled. Untuk mengaktifkannya, tim IT Intiwarna / supplier mesin cat (Corob / Fast & Fluid) perlu menyediakan spesifikasi software dispenser, koneksi COM Port / serial driver, atau database formula warna cat yang digunakan di toko.

business PIC: Supplier Mesin Cat & Klien Intiwarna Outstanding
02

Kredensial Akun Merchant Payment Gateway Website

Modul Website E-Commerce sudah berfungsi penuh untuk registrasi, keranjang belanja, checkout, dan katalog 19,000+ produk. Agar transaksi pembayaran online langsung memotong kartu kredit/QRIS di web, Klien perlu memberikan API Key Merchant (Midtrans / Xendit / Doku).

vpn_key PIC: Tim Keuangan Intiwarna Pending Data
03

Alokasi Kuota Cuti Tahunan & Pemrosesan Payroll Rutin

121 master karyawan sudah terdaftar lengkap di database. Untuk mengaktifkan alur cuti mandiri secara penuh, HRD Intiwarna perlu menginput hak sisa cuti tahunan awal setiap karyawan. Modul payroll custom juga sudah siap mengkalkulasi insentif dan potongan pinjaman.

person_pin PIC: HRD Intiwarna Pending Data
04

Template Mutasi Rekening Koran Bank (Bank Statement Import)

Fitur rekonsiliasi bank otomatis sudah siap di modul Accounting. Tim finance Intiwarna hanya perlu mengunduh mutasi rekening koran dari internet banking (BCA / Mandiri) dalam format CSV atau Excel untuk disamakan kolomnya dengan Odoo.

account_balance PIC: Finance Intiwarna Selesai / Terverifikasi
